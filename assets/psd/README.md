# Referências PSD exportadas

Os 20 PSDs fornecidos foram exportados para PNG aqui como referências de paleta, silhuetas e efeitos. A renderização do jogo **não** usa esses recortes diretamente: nave, fundo, tiros, asteroides e efeitos continuam desenhados com Canvas/SVG para evitar os fundos e cortes estranhos da prancha. Os PSDs originais não foram modificados.

## Guia de referência

- 1–3 e 8: linguagem visual de disparos e explosões.
- 4–6: paletas e detalhes de armadura alienígena.
- 7: contorno e brilho do escudo.
- 9: emblema planetário/UI.
- 10, 12–14: nebulosas, galáxias e cometa.
- 11: asteroide com rastro.
- 15–20: paleta e detalhes de planetas.

Para reexportar os PSDs como PNG, execute `python tools/export_psd_assets.py "C:/caminho/para/PSD"`.
